# market_onlain_homework

# Интернет-магазин (ядро на ООП)

## Описание
Проект реализует базовые сущности для интернет-магазина:
- **Товары** (`Product`): название, описание, цена, количество.
- **Категории** (`Category`): название, описание, список товаров.

## Установка
1. Клонируйте репозиторий:
   
   git clone https://github.com/ваш-репозиторий.git
   
***Установите зависимости:***

poetry install  # или pip install -r requirements.txt

***Запуск тестов:***

pytest tests/

***Структура проекта:***

**src/models/**— основные классы.

**tests/** — модульные тесты.

**data/** — JSON-файлы для загрузки данных.
