# market_onlain_homework

# Интернет-магазин (ядро на ООП)

## Описание
Проект реализует базовые сущности для интернет-магазина:
- **Товары** (`Product`): название, описание, цена, количество.
- **Категории** (`Category`): название, описание, список товаров.

## Установка
1. Клонируйте репозиторий:
   
   git clone https://github.com/ваш-репозиторий.git
   
***Установите зависимости:***

poetry install  # или pip install -r requirements.txt

***Запуск тестов:***

pytest tests/

***Структура проекта:***

**src/models/**— основные классы.

**tests/** — модульные тесты.

**data/** — JSON-файлы для загрузки данных.

# Магазин электроники и товаров для сада

Проект реализует систему учета товаров для магазина с категориями "Электроника" и "Сад".

## Новые возможности в текущей версии

### 1. Расширенная система классов продуктов

Добавлены специализированные классы товаров:

#### Класс `Smartphone` (наследуется от `Product`)
Дополнительные атрибуты:
- `efficiency` - производительность (числовой показатель)
- `model` - модель телефона
- `memory` - объем встроенной памяти (в ГБ)
- `color` - цвет устройства

#### Класс `LawnGrass` (наследуется от `Product`)
Дополнительные атрибуты:
- `country` - страна-производитель
- `germination_period` - срок прорастания
- `color` - цвет травы

### 2. Улучшенные операции с товарами

#### Безопасное сложение товаров
- Реализована проверка типов при сложении товаров
- Можно складывать только товары одного типа (смартфоны со смартфонами, траву с травой)
- При попытке сложить разные типы товаров вызывается `TypeError`

Пример:
```python
smartphone1 + smartphone2  # Работает
smartphone + lawngrass     # Вызовет TypeError

# Создание смартфона
iphone = Smartphone(
    "iPhone 15", 
    "Флагманский смартфон", 
    120000, 
    10, 
    98.5, 
    "15 Pro", 
    256, 
    "Титановый"
)

# Создание газонной травы
grass = LawnGrass(
    "Трава элитная", 
    "Для футбольных полей", 
    1500, 
    50, 
    "Германия", 
    "14 дней", 
    "Изумрудный"
)

# Сложение товаров одного типа
total_value = iphone + Smartphone("Galaxy", "...", 90000, 5, ...)

# Работа с категориями
electronics = Category("Электроника", "Техника")
electronics.add_product(iphone)  # Успешно
electronics.add_product(grass)   # Вызовет TypeError
```
**запуск тестов**

pytest tests/ --cov=src --cov-report=html

## Функциональность + ДЗ 17.1

### Реализованные классы

#### Базовые классы
- **`BaseProduct`** - абстрактный базовый класс для всех продуктов
- **`Product`** - основной класс товара (наследуется от `BaseProduct` + `LoggingMixin`)
- **`Category`** - класс категории товаров

#### Специализированные продукты
- **`Smartphone`** - класс для смартфонов (наследуется от `Product`)
- **`LawnGrass`** - класс для газонной травы (наследуется от `Product`)

#### Вспомогательные классы
- **`LoggingMixin`** - миксин для логирования создания объектов
- **`ZeroQuantityError`** - пользовательское исключение
